# Debug logs (`DOCS/debugs/`)

Session debug write-ups live here as `debug_[timestamp].md` per `CLAUDE.md` / `AGENTS.md` error workflow.

**Format:** What failed → what was tried → outcome → next step.

**Player-facing release notes** belong in `ui/components/ChangelogScreen.kt` (`APP_CHANGELOG`), not this folder.

**Future work / suggestions** belong in **`DOCS/FUTURE UPDATES/`** — see [`FUTURE UPDATES/README.md`](../FUTURE%20UPDATES/README.md).
